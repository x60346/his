開場前準備

提前 10 分鐘
  • 用線上網址，不要用本機開發伺服器；在要上台的那台電腦、那個瀏覽器先完整走一遍。
  • admin 登入 → 系統管理 → 展示資料，「重置時的醫院規模」維持小型醫院 → 按 重置為今天的展示資料 → 確認「重置」。資料會以「今天」為基準重建，所以每次重置後日期、住院天數可能不同；找病人一律用姓名，不要背床號或日期。
  • 開兩個分頁並排（左右各半個螢幕）。兩個分頁共用同一份資料，但登入身分各自獨立：左邊登醫師、右邊登藥師或護理師，一邊開醫囑，另一邊的數字會自己更新。
  • 畫面 15 分鐘沒動作會鎖定（不是登出），輸入 1234 就解鎖，寫到一半的東西還在。
這是前端展示版：沒有後端，資料存在這個瀏覽器裡，病人、醫師都是虛構的。重點是流程和規則，不是介面長怎樣。

門診：開錯會被擋，而且講清楚為什麼

6 分鐘

主角李美玲（病歷號 100002）對 Penicillin 過敏，這是固定的示範資料。

  1. clerk01掛號作業右分頁
    • 搜尋「李美玲」：病人卡一次看到過敏 Penicillin、慢性病連續處方（下次可領的日期）、可加做的預防保健。
    • 重置後她已經掛好林子謙醫師上午診 1 號、已報到，不用再掛；指給觀眾看「已有預約：…已報到」就好。

    想示範掛號本身，就另外找一位病人掛號：選診次 → 確認區顯示預估應收 → 掛號（預設「同時報到」）。

  2. dr01門診看診左分頁
    • 左邊候診清單點李美玲：右上角紅色「過敏：Penicillin」，上方還有外院轉診單。
    • 按 叫號・開始看診 → 診斷輸入 J06 按 Enter。
    • 藥品搜尋 Amox → 選 Amoxicillin 500mg：這一列立刻標「病人對 Penicillin 過敏」。
    • 按 完成看診 → 跳出「過敏警示」，要醫師明確確認。
    • 按取消、按這一列右邊的刪除，改從組套選「上呼吸道感染」→ 套用。
    • 套用後馬上出現黃色「用藥提醒：重複用藥」：她耳鼻喉科開的 Acetaminophen 還沒吃完。
    • 按完成看診 → 提醒要確認，說明欄寫「已叮囑病人停用耳鼻喉科的普拿疼」→ 確認，仍要開立。
    不是不能開，是要醫師明確確認、留下紀錄。系統把風險擺在眼前，決定權還在醫師；醫師寫的理由，等一下藥師也看得到。
  3. clerk01批價結帳右分頁
    • 清單上就看得到預估應收 → 收款 → 印收據。
  4. ph01門診藥局右分頁
    • 輸入領藥號 1 按 Enter：上方黃框是「醫師開立時已確認」的重複用藥提醒，連同醫師寫的理由。
    • 按 核對處方 → 發藥 → 逐項掃藥品條碼。用「示範：模擬掃描」先選「拿錯：Ibuprofen」，當場紅字擋下；再依序選三個正確的藥 → 確認，下一步。
    • 確認領藥人：請病人說出姓名與生日，輸入月日 0105 → 確認發藥。庫存數字當場扣掉。

    時間不夠時，3、4 步只講不做。

住院重症：一位病人、一條故事線

8 分鐘

主角羅志偉，主治 dr03 黃柏翰（內科）。

  1. dr03首頁左分頁
    • 最上面「待確認的報告」：羅志偉，住院危急值，飯前血糖 32 ↓。
    • 下面是待辦卡片：NEWS2 警示、加護病房轉入、鎮靜超出目標、值班紀錄待看…；沒有待辦的收在「另有 N 項目前沒有待辦」。
    • 點任一張卡（例如「傷口 2 週沒變小」）→ 直接帶到那位病人、那個分頁，上方列出這張卡涵蓋的病人。
    醫師不用自己去翻每一位病人，要處理的事會被送到面前，一點就到。
  2. dr03住院醫囑 → 羅志偉（ICU）

    剛從待辦卡片進來時，左邊清單上方有待辦篩選，分頁也停在那張卡的分頁：先按篩選旁的「關閉」，或從左邊選單重新點「住院醫囑」，再點羅志偉。

    • 病人上方由上而下：值班紀錄（夜間發燒 38.6°C、抽血培養兩套）→ 危急值紅條（血糖 32）→ 外科會診待回覆（左足大拇趾傷口紅腫滲液，評估清創）→ 入院診斷 E11.10 糖尿病酮酸中毒。
    • 分頁「急救」：心室顫動、電擊、Epinephrine，抽血 K 2.6 補鉀，恢復自主循環，轉加護病房；每一筆記錄是誰做的。
    • 分頁「加護病房」：每日 SOFA、APACHE II 與預估死亡率；轉出摘要還沒寫，住院中心就不能把他轉出去。
    足部感染誘發酮酸中毒，治療中低血鉀引發心室顫動，急救後轉加護病房；夜裡發燒、會診外科看傷口；今天打胰島素點滴時血糖掉到 32。每件事都有通報、有人接、有紀錄。
  3. dr03 左分頁 ＋ ph01 右分頁兩邊並排
    • 右分頁 ph01 停在首頁，先指給觀眾看「住院醫囑待審核」的數字。
    • 左分頁羅志偉切到「醫囑」分頁 → 新增醫囑 → 給藥、長期 → 搜尋 Omeprazole → 開立。
    • 右分頁的數字自己加 1，不用重新整理。
    • 右分頁進 住院藥局 → 醫囑審核：剛開的 Omeprazole 在清單上，系統沒找到問題 → 通過。
    • 再點清單上潘家銘的 Ibuprofen：系統列出「同類重複」（和 Celecoxib 都是止痛消炎藥）、「腎功能」（7 天內沒有肌酸酐），藥師可以「疑義」退回醫師。
    醫師一開完，藥師那邊馬上看到；長期醫囑要藥師審過才會進每日調劑。

護理站：給對人、給對藥，給錯了怎麼留紀錄

5 分鐘
  1. nurse01護理站右分頁
    • 上方切換病房；「本班待辦」依急迫排序（逾時紅、現在黃），旁邊是全病房逾時給藥、待執行臨時醫囑的數字。
    • 登入的是當班護理師時（上方人力列寫著這一班是誰；nurse01 排白班），還會有「我的病人／全病房」切換。
  2. 點潘家銘（5A 內科病房）→ 給藥紀錄
    • 在 08:00 Celecoxib（或任何一筆到時間的藥）按 給藥 → 跳出「給藥前核對：掃描條碼」。
    • 沒有掃描槍，用下方「示範：模擬掃描」：先故意選「腕帶：別床病人的腕帶」，當場紅字「病人不對！這是 505-1 … 的腕帶」，並記一筆「差點給錯」。
    • 再選「腕帶：本人腕帶」和「藥品：正確的藥」→ 確認，繼續給藥。
    掃錯人、拿錯藥，在給下去之前就被擋住，而且這次「差點出錯」也會記下來，之後可以檢討。
  3. 同一筆紀錄 → 更正
    • 剛給完的那一列有 更正：改成「暫停」，原因點快選「紀錄錯誤（按錯列，藥其實沒給）」→ 更正為暫停。
    • 原本的紀錄沒有消失，下方標「更正 時間・誰：原記已給藥 時間・誰」。
    病歷只能增補、不能改寫。改了什麼、誰改的、為什麼改，全部留著。

    更正有限制：8 小時內、只限長期排程的藥；管制藥、臨時與需要時給的藥不能改成沒給。

現場注意

要做

  • 每一段從首頁待辦出發，讓觀眾看到事情是被送來的。
  • 一開始就交代這是展示版，主動提 README〈已知的簡化與限制〉，比被問倒好。
  • 操作改亂了：admin 重置展示資料，一分鐘回到初始狀態。

不要做

  • 不要從選單逐頁點過去；功能太多，會失焦。
  • 不要背床號、日期、住院第幾天；每次重置都可能不同，用姓名找人。
  • 不要在台上第一次走某個流程；沒預演過的就不要臨時加。
